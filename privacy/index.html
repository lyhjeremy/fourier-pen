Privacy

Last updated 2026-10-14.

Pictures you upload

A picture you choose, drop or paste is read by your browser and processed there. It is never sent to a server. There is no code path in this site that uploads an image anywhere. You can check this in the source: the only network request the page makes is the one described in the next section.

Text prompts

If you type a text prompt and press "Draw it", the text you typed is sent to this site's own server function, which wraps it in a fixed instruction and sends it to an image model hosted by Cloudflare (Workers AI, the FLUX.1 schnell model). Cloudflare receives the prompt text and returns an image; its handling of that request is covered by Cloudflare's privacy policy. The function can alternatively be configured to use Google's Gemini image model, in which case the Gemini API terms apply instead. The server function does not store the prompt or the image, and it logs only the outcome of the request (success, rate limited, blocked, failed) and the prompt's length, never its content.

The server also sees your IP address, which it uses only to limit how many prompts one address can send in a ten-minute window. Those counts are kept in memory for at most ten minutes and are never written anywhere.

Saved files

PNG, SVG, CSV and video files are generated in your browser and downloaded directly. They do not pass through a server.

Cookies, analytics and third parties

There are no cookies, no analytics and no third-party scripts. Fonts are served from this site. The page stores one value in your browser's local storage: your theme choice (light, dark or system), if you set one. Clear your browser's site data to remove it.

Hosting

The site is hosted on Vercel, which keeps standard web server request logs (IP address, user agent, URL, time) for its own operations. Those logs are governed by Vercel's privacy policy.

Deletion requests

Nothing you enter is retained by this site, so there is nothing to delete. For anything about Vercel's or Google's logs, use the links above. For questions about this site, email lyhjeremy@gmail.com.
