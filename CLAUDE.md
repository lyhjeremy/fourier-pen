# Fourier Pen

A website that turns any picture (uploaded, or generated from a text prompt) into one continuous line and redraws it with a chain of spinning arrows: a complex Fourier series, epicycle style.

Read `docs/spec.md` before changing behaviour and `docs/architecture.md` before adding a file. Record any new judgment call in `docs/decisions.md`.

## Stack

- Front end: plain HTML, CSS and JavaScript ES modules. No framework, no bundler, no npm dependencies in the browser code.
- Back end: one Vercel serverless function, `api/generate.js`, that calls the Gemini image API for the text prompt feature. That is the only server code.
- Hosting: Vercel at https://fourier-pen.vercel.app/. Pushing to `main` deploys.
- Design: the Ledger house style in https://github.com/lyhjeremy/lyhjeremy/blob/main/DESIGN_STANDARDS.md. Run `python3 "../_ai-projects-tooling/ledger/designcheck.py" .` before every commit; it must exit 0.
- Tests: `node --test tests/` against the pure modules (edges, path, fourier). No browser test runner.

## Layout

```
index.html          the page (single page, no routing)
styles.css          all styles, tokens on :root
js/
  main.js           boots the app, wires UI to pipeline
  edges.js          grayscale, blur, Canny, stroke tracing
  path.js           stroke ordering, MST bridges, Euler tour, resampling
  fourier.js        DFT, coefficient sorting, curve rebuild
  render.js         canvas animation
  exports.js        PNG, SVG, CSV, WebM
  prompt.js         text prompt client (calls /api/generate)
  samples.js        built-in example pictures
  ui.js             DOM lookup, labels, sliders
api/
  generate.js       Vercel function: prompt -> line-art image
tests/              node --test files for pure modules
docs/               spec, architecture, design, decisions, build plan
overview/           the writeup page, GENERATED by ../_ai-projects-tooling/overview-pages/build.py; edit the fragment, not this
privacy/, terms/    required by the design standards because api/ exists

fonts/              self-hosted Source Serif 4, IBM Plex Sans, IBM Plex Mono
```

## Running

```
npx serve .             # static site, no text prompts
vercel dev              # static site plus /api/generate, needs GEMINI_API_KEY in .env.local
node --test tests/      # unit tests
```

## Rules

- Keep `edges.js`, `path.js` and `fourier.js` free of DOM access so they stay testable in Node. They take typed arrays and return typed arrays or plain objects.
- Never put a secret in the repo. `GEMINI_API_KEY` lives in Vercel project settings and in `.env.local`, which is gitignored.
- `test-images/` stays gitignored. The Einstein photo in it is a Getty news photo and must not be shipped or committed.
- The `prototype/` folder is the reference for behaviour parity. Do not edit it; port from it.
- UI strings use sentence case and plain words. No em dashes anywhere in the repo (see the global writing rules in `~/.claude/CLAUDE.md`). Numeric ranges may use an en dash.
- Drawing defaults are fixed in `docs/spec.md`. Change the spec first, then the code.
- Commit messages: one short line in the imperative, a blank line, then why if it is not obvious. No AI co-author or "generated with" trailer: the portfolio's publishing checklist forbids it.
- The writeup at `overview/index.html` is generated. Edit `../_ai-projects-tooling/overview-pages/fragments/fourier-pen.html` and rebuild.
