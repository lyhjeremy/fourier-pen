# Handoff: Fourier Pen

**Status:** shipped and live. Built 2026-10-14; last touched 2026-10-14.
**Repo:** https://github.com/lyhjeremy/fourier-pen · **Live:** https://fourier-pen.vercel.app/
**Local folder:** `6. Data Projects/Project 36 Fourier Pen`

## What it is

A browser tool that turns any picture (or a text prompt) into one continuous line and
animates a chain of rotating arrows drawing it: a complex Fourier series you can watch,
read and export. Distinctive parts: the pen never lifts (minimum spanning tree bridges
plus an Euler tour), the coefficients are shown as real numbers, and exports go to
wallpaper sizes and video.

## How it works

`picture -> grayscale -> Canny -> trace strokes -> MST bridges -> Euler tour -> resample N -> DFT -> sort by |c_n| -> draw first K arrows`

Text prompts: `prompt -> api/generate.js -> Gemini Interactions API (model gemini-nano-banana-2.1) -> PNG -> same pipeline`.

## Key files

- `js/edges.js`, `js/path.js`, `js/fourier.js`: pure modules, tested under Node.
- `js/render.js`: `drawScene` draws into any 2d context; the stage and the video exporter share it.
- `js/exports.js`: PNG, SVG, CSV, WebM/MP4 (MediaRecorder, real time, capped at 1920 px).
- `js/main.js`: state, wiring, `window.fourierPen` debug hook used by the screenshot scripts.
- `api/generate.js`: the only server code. Validates, rate limits per instance, calls Gemini.
- `styles.css`: Ledger tokens from DESIGN_STANDARDS.md; the stage is `--panel` with `--ink` lines.
- `overview/index.html`: generated by `_ai-projects-tooling/overview-pages/build.py` from `fragments/fourier-pen.html`. Do not edit the output.
- `samples/einstein.jpg`: the one shipped picture, public domain (Library of Congress).

## Environment notes

- `GEMINI_API_KEY` was not available on this machine at build time, so the prompt path is deployed but untested end to end. The function returns `{error:'unavailable', reason:'not_configured'}` without a key and the UI says so. First thing to do: add the key in Vercel project settings and try "a bicycle".
- The Gemini request uses the Interactions endpoint documented at ai.google.dev on 2026-10-14 (`POST /v1beta/interactions`, `response_format: {type:'image', mime_type:'image/jpeg'}`; PNG is rejected). `findImage()` in the function searches the response for any `{type:'image', data}` block, so a change in response shape is survivable. The old `generateContent` shape is not used.
- Rate limiting: the Vercel WAF rate-limit rule (Hobby allows up to 3 custom rules) must be added in the dashboard; it is not in the repo. The in-function limiter is per warm instance only.
- `ffprobe` on this machine is broken (missing libx265), so the WebM was verified by size and by the browser's own recorder state, not by decoding.
- Google Drive folder: large screenshot runs should go to the scratchpad, not the project folder, or Drive syncs them.
