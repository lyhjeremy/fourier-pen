Fourier Pen

Any picture, one line, a chain of spinning arrows. The page finds the outlines in a picture, threads them into a single continuous line, and redraws that line with rotating arrows stacked tip to tail. Each arrow is one term of a Fourier series.

Preparing

Pictures you upload never leave your browser. A text prompt is sent to an image model (Cloudflare Workers AI) through this site's server. Privacy.

Picture

An image model draws a line-art version, then the page traces it. Takes a few seconds.

The maths

cn = 1N Σk zk e−2πink/N

Each point on the line is a complex number zk. Each coefficient cn is one arrow: its size is |cn|, and it turns n times per drawing. The biggest arrows are drawn first.
